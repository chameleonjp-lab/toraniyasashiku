# 虎に優しく：共通仕様のDraftと公開手順

この変更は既存ゲームの共通UI・ランキング連携をレビューするためのDraftです。GitHub Pagesへの実公開、設定変更、マージ、実APIへの試験送信は行っていません。既存READMEは変更しません。

## 実装と保持範囲

- ゲーム識別子は `torani_yasashiku`。リポジトリ名 `toraniyasashiku` に合わせて既存の識別子・保存キーを変更しません。
- 60秒から開始し、虎 +200点／落下 -3000点、お風呂 -700点、ほうれん草のタップ +200点／放置1.5秒ごと -600点、時計 -3秒、男の子 +3秒／逃すと -2秒、Wi-Fiで虎3体追加／逃すと -3000点という元のルールを保持します。整数の点数で、大きいほど上位です。
- 元のゲーム入力、出現・衝突・移動・時間・難易度・記録のルールはこの公開準備で変更しません。リタイア時の送信経路も元の動作を保持し、新たな「非送信」仕様とは説明しません。
- ホームの名前は任意。入力を開始時に固定し、空欄は保存名で補完せず匿名で開始、匿名ではスコアRPCを呼びません。元の20 UTF-16コード単位上限を維持します。名前は本人認証ではありません。
- 15言語の選択とカタログ、保存設定→ブラウザー言語→英語の選択、ルール・結果・ランキングなどの翻訳を追加しています。ただし元の男の子の反応文は意味を変えない翻訳が未確定で、`boyReaction` は全言語で `null`、元の表示を保持します。全画面・全文言の翻訳完了やネイティブ確認済みとは主張しません。
- ホーム・結果のX共有、黒白ボタン、現在の結果点数と旧正式URL、`#虎に優しく #ゲーム制作` の2タグを使用します。自動投稿はしません。popupが利用できない場合のみ手動コピー用の文面を提示します。実X・referrer挙動は未検証です。
- SEは初期ON・音量50%。保存済みOFF/音量0を尊重し、操作を契機に初期化します。非表示・消音時の発音停止、短時間の重複制御、失敗の非伝播を実装しています。実音・実端末の復帰は未検証です。
- 結果アクションをランキングより前に配置。既存のベスト／初回ランキングRPCに `p_limit:30` を渡し、表示も30件に制限します。読取再試行はスコア再送と分離しています。
- 現通常ランキングの `rank_no` を表示し、同点の `1,1,3` とAPI順序を保持します。順位は正のsafe integerのみ採用し、不明値を行番号で代用しません。同名の行を独自統合しません。
- 通常8列ACKの形状・名前・整数点数・DESCの整合性を検証し、HTTP成功だけで確定しません。不正・不明応答でも結果を保持し、スコアを自動再送しません。古い通信が次のプレイの結果を上書きしないようにしています。

## スコア契約と未解決の境界

通常ACKは `accepted / result_normalized_name / result_display_name / result_first_score / result_best_score / result_play_count / is_first_play / is_new_best` の8列です。9列の別wrapperを仮定しません。検証は固定した送信名前・点数を使い、サーバーの名前比較はU+0020の前後除去だけを扱います。新規入力の点数範囲と既存履歴のint4範囲を区別します。

これは応答の整合性検証であり、永続保存のreadback、同名別人の識別、本人認証、送信の冪等性の保証ではありません。現ランキング表示には従来の数値文字列変換とscore/name別名fallbackが残っています。`rank_no` 修正によってこの別のスキーマ境界まで厳密になったとは説明しません。

匿名開始の計測は公開スコアと別契約です。このPRでは推測した計測エンドポイントやDB変更を追加しません。実験場側の集計・匿名ポリシー・実スコア連携は、適切な契約確認と関連PRで追跡します。

## ファイルと検証

実行時のローカル配布物は `index.html` 1ファイルです。純粋helperと15言語カタログはHTMLへインライン化済みで、同梱の `.cjs` / `.js` / `.json` は編集・回帰テスト用の対応ソースです。既存のSupabaseブラウザーライブラリはCDN参照のままです。これはオフライン動作・CDN可用性を保証しません。

パッケージ導入やビルドは不要です。以下はNode標準モジュールだけを使い、選んだ関数をfake環境で実行する限定テストです。ゲーム全体、ブラウザー、実音、実RPCは動かしません。

```sh
node test/rpc-rank-no.test.cjs
node test/normal8-actual-caller.test.cjs
node test/participation.test.cjs
node test/public-stage.test.cjs
```

最初の3本は順位24・通常ACK18・参加状態11の合計53ケースです。最後は固定runtime、インラインソースとの一致、実行しない構文検査、言語と識別子、画像pendingの静的境界を確認します。これは端末・全UI・APIの結合試験ではありません。
